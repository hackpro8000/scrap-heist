# Settled findings

Findings a critic withdrew after checking proof, so a fresh critic doesn't raise them again from nothing. The main session hands this file to every critic with the rules. A settled finding may be raised again only with new evidence the critic names (a render, a measurement, a crop). Each entry: the claim, what settled it, the date. Entries are removed when the thing changes enough that the proof no longer holds.
